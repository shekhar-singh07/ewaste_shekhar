## 📌 Overview
An integrated coursework portfolio dashboard presenting state-level policy trackers, hydrothermal buffering, compliance audits, LEED green building scorecards, circular economy case studies, and machine learning research in electronics waste management.

### 🚀 Highlights & Features
- **Cyber-Ecological Aurora Design:** High-contrast aesthetic with neon cyan (`#00E5FF`) and emerald (`#00F298`) accents.
- **Instant Search & Filtering:** Filter submissions across categories or use the instant keyword search bar.
- **Direct Asset Downloads:** Includes reports, presentation decks, data workbooks, posters, and diagnostic infographics.
- **Live Dashboards:** Links to live interactive tools including the UP State Scorecard, Reclaim Atlas 3D Globe, LEED Green Building interactive evaluator, and the public EPR compliance tool.

## 💻 Running Locally
Simply open `index.html` in any modern web browser or serve it via a local web server:
```bash
# Using Python
python -m http.server 8000

# Using Node.js
npx serve .
```
Navigate to `http://localhost:8000` to explore the portfolio.
